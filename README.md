# 怎么往 Food's Map 里加一家新餐厅

所有餐厅都在一个文件里：`restaurants.csv`。网页本身不用改，只改这个表格。

## 最简单的做法（Excel / Numbers / Google 表格）

1. 用 Excel 或 Google 表格打开 `restaurants.csv`。
2. 在最后加一行，按下面的列填写。不确定的格子可以先空着。
3. 保存时选 **CSV UTF-8** 格式（否则中文会乱码）。
4. 把新的 `restaurants.csv` 上传到网站所在的位置，替换旧文件（GitHub 上直接在网页里点 "Add file → Upload files" 覆盖即可）。

也可以直接把店名发给 Claude，让它帮你查资料、补齐整行再更新。

## 每一列填什么

| 列名 | 填什么 | 例子 |
|---|---|---|
| name | 餐厅正式名称 | Bistecca |
| original_names | 你收藏时写的名字，多个用 `\|` 隔开（用于去重） | Bornga\|Bornga BBQ |
| cuisine | 菜系，尽量用已有的分类（见下） | 意大利菜 |
| area | 具体区域/商场 | CBD（Dalley St） |
| region | 大区，尽量用已有的分类（见下） | 市中心 CBD |
| meals | 推荐时段，用 `\|` 隔开 | 午餐\|晚餐 |
| price | 人均：`$` / `$$` / `$$$` / `$$$$` | $$$ |
| score | 打卡指数，1.0–5.0，留空显示"未评分" | 4.5 |
| highlights | 一句话特色 | 佛罗伦萨 T 骨牛排 |
| lat | 纬度 | -33.8630 |
| lng | 经度 | 151.2085 |
| confidence | 确认 / 较确定 / 猜测 | 确认 |
| note | 备注（比如"有多家分店"） | |

**怎么拿经纬度：** 在 Google 地图上右键点餐厅位置，弹出的第一行数字就是"纬度, 经度"，点一下就复制了。lat/lng 留空的话，餐厅只出现在列表里，标"位置待确认"，不会出现在地图上。

**已有的菜系：** 意大利菜、法餐、日料、韩餐、泰餐、马来/南洋、中餐、火锅、牛排/烧烤、现代澳洲菜、咖啡/早午餐、甜品/咖啡、拉美菜、巴西烤肉、西班牙/地中海、中东/埃及菜、希腊菜、印度菜、汉堡/快餐、酒吧/小食。写新的菜系也可以，筛选菜单会自动多出一项（地图上用灰色点）。

**已有的大区：** 市中心 CBD、中国城/Haymarket、环形码头/The Rocks/Barangaroo、达令港/Pyrmont、东区内城、南区内城、内西区、东部海滩、北岸、西区、南区。

**时段可选：** 早餐、早午餐、午餐、下午茶、晚餐、宵夜。

## 注意

- 表格里的文字如果有英文逗号，Excel 会自动处理，不用管；如果用记事本直接改，含英文逗号的格子要用英文双引号包起来。
- 打卡指数是根据网上评价、获奖情况和餐厅特色给的参考分，不是某个平台的官方评分，可以按自己的体验改。
